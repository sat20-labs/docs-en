# Partners and Contribution Guide

External teams may contribute code, documentation, translation, nodes, testnet validation, liquidity, content, and security audits. Every contribution should name the repository and scope, include reproducible evidence, and keep mnemonics, node keys, and production configuration out of submissions.

Protocol changes must describe effects on the Indexer, SatoshiNet, Wallet SDK, Transcend, and documentation. Documentation updates should establish the Chinese facts first and then synchronize the English page. Testnet evidence should record the network, time, height/hash, transaction, contract, and known limits.
