# Built on SatoshiNet

This page lists projects, tools, and cases that are currently accessible or under testnet validation. A status does not imply third-party audit, liquidity, or a long-term SLA.

## Current Reference Implementations

| Type | Project | Status and Entry |
| --- | --- | --- |
| Wallet | SAT20 PWA Wallet | [Entry](https://sat20.org/pwa/); mainnet/testnet, L1/L2/Channel, Market, Tools, and account management continue to iterate |
| L2 Market | SAT20 / SatoshiNet Market | [Mainnet](https://satsnet.ordx.market/swap/?network=mainnet); [Testnet](https://test-satsnet.ordx.market/swap/?network=testnet); current docs cover AMM and limit orders |
| Indexer | SAT20 L1 / SatoshiNet L2 Indexer | Implemented; see [API Source Map](../build/api-source-map.md) and [Operations](../run/indexer.md) |
| Explorer | SatoshiNet Explorer | [Mainnet](https://mempool.sat20.org/), [mainnet app explorer](https://mainnet.sat20.org/browser/app/), and [testnet app explorer](https://testnet.sat20.org/browser/app/) |
| Smart Contracts | Template / Agent / EVM Runtime | Public-testnet iteration through PWA `Tools -> Smart Contracts`; see [Contract Catalog](../build/contract-template-catalog.md) |
| Agent | SAT20 Agent Wallet | Archived testnet drills and safety evidence; see [Validation Record](../ai/sat20-agent-wallet/testnet-validation.md) |

Launchpad, DAO, and community-fund historical runtimes are not automatically listed as public products. They require a current entry, registered contract, and reviewable evidence.
