# Docs Success Metrics

Documentation success is not measured by page count or traffic alone. Monthly review should cover correctness (broken links, source-path errors, stale status, bilingual drift), executability (quickstart completion and reproducible evidence), ecosystem conversion, and support cost.

Metrics must distinguish internal tests, external users, testnet, and mainnet. Automated acceptance traffic must not be counted as adoption, and wallet telemetry must never collect mnemonics, complete addresses, or AccountSecret values.
