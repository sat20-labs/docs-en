# Community DEX / DAO Quickstart

This page is an integration checklist for a community testnet DEX prototype. Reference markets, wallet connection, AMM, and limit-order components are available, but a public DAO entry and standardized white-label package are not.

## Goal

A BTC community should be able to:

1. Choose community assets.
2. Deploy or configure a DEX frontend.
3. Configure AMM or limit order modules.
4. If a DAO or community fund is required, complete a separate contract-model and security review; the public PWA has no general entry today.
5. Integrate wallet, Indexer, and Explorer.
6. Complete a test transaction.
7. Generate user docs and risk notes.
