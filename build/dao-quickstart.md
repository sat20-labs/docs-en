# Deploy a Community DAO

The Wallet SDK retains the DAO channel-contract runtime, including UID, referral, donation, and airdrop state handling. This does not mean that the SatoshiNet smart-contract template catalog currently exposes a DAO template or that the PWA offers a public one-click deployment flow.

Before opening deployment, the contract model, permissions, fees, failure rules, testnet evidence, PWA approval flow, and Explorer/Indexer visibility must be fixed and verified. New work must also state clearly whether it uses a channel contract or a SatoshiNet smart-contract template.
