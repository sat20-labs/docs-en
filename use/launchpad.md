# Join a Launchpad

The current PWA release has no standalone public Launchpad entry. LaunchPool/Launchpad channel-contract runtime is a lower-level capability; a user flow exists only after an operator publishes the site, network, asset, contract, peer, rules, and test evidence.

Until then, do not transfer assets to an unknown address claiming to be a SatoshiNet Launchpad. A future campaign must expose its deployment transaction, funding and refund rules, AMM handoff, administrator permissions, and Explorer/Indexer verification method.
